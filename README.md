# Nona Dronova Virtual Museum

Nona Dronova Virtual Museum — a digital museum of botanical expressionism, painting, garden art, artistic interior textiles, and the LIBERI silver jewelry collection. A space for artistic research, creative education, innovation, and the preservation of artistic heritage.

**Виртуальный музей Ноны Дроновой** — цифровой музей ботанического экспрессионизма, живописи, садового искусства, авторского интерьерного текстиля и серебряной ювелирной коллекции LIBERI. Пространство художественных исследований, творческого образования, инноваций и сохранения художественного наследия.

Двуязычный (RU/EN) статический сайт виртуального музея: живопись, сад «Папоротники и мох» как основа экспозиции,
теория современной живописи, художественный текстиль, серебро LIBERI, научный каталог.

## Устройство
- `public/` — готовый сайт (его публикует Vercel). Русская версия в корне, английская — в `/en/`.
- `public/data/catalog.json` — научный каталог (источник истины для карточек произведений). Неустановленные поля = `null`.
- `public/img/l`, `public/img/s` — изображения WebP (1600 и 640 px), извлечённые из репозиториев Nona1960 без кадрирования.
- `tools/build.py` — генератор страниц; `tools/content_*.py` — тексты; `tools/site.css` — дизайн-система.
- `tools/ingest.py` — первичный сбор каталога из репозиториев (выполнен 19.10.2026; повторный запуск переназначит ID — не запускать без необходимости).

## Сборка
```
pip install pillow
python3 tools/build.py
```
